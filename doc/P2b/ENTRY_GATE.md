# P2b 分级准入 Gate（不得合并）

## 0. 已知实际证据与缺口

- P2a 构建与 U01–U04 HOST：根据 `doc/P2a/P2a_HANDOFF.md` 记录 PASS；本包不重新执行。
- 用户这次的 LA 图片：支持约 102 Hz 周期性通信活动、约 238.9 µs 片选活动窗口，**仅 H02 时序片段**；并不证明身份/配置/数据值/姿态角/驱动关闭。
- H01（ID及配置解码）、H02（原始字节倾斜验证）、H03（PC6/PC7保持低电平）、H04（断电移除传感器失败关闭）尚未收到可独立复核的完整证据：`NOT_VERIFIED`，不可推断 PASS。
- 旧 `P2a_HANDOFF.md` 的 H01–H04 仍是 `NOT_RUN`，Codex 可追加新现场实测但不能覆写历史或假装自己测试硬件。

## G0 — 开始 P2b 软件开发：可以

前提：核对最新 main SHA 和工作树；复读 P1 Control/Actuator、P2a Imu 接口；不改 P1 安全机制；默认编译运行不输出 PWM。允许写 `LOCAL_IMU`、映射、ControlTask 集成、KEY0/KEY1 最小授权及 HOST 测试。

## G1 — 烧录 P2b 无负载测试固件：需核查

- P2b BUILD/HOST PASS、互斥宏守卫确认、产物 HEX SHA256 记录。
- 真实板卡确认 KEY0=PE4、KEY1=PE3，低电平按下，内上拉；按键未与当前 P1/P2a 引脚冲突。无法确认则先停止输出镜像烧录，改用软件无输出路径。
- 舵机信号和独立供电物理断开；已用 P2a 捕获 SPI ID/配置/连续 burst 合理性；明确操作员无负载授权。
- 先上电确认 KEY0 未按情况下 PC6/PC7 无 PWM，再按 KEY0 使能，测中位帧及受限跟随，KEY1 关闭。

## G2 — 接入真实舵机（带载）：不满足时禁止

- G1 的真实波形已证明轴向/方向/范围/变化速率和 KEY1 停止符合预期。
- P2a H01、H02 关键原始数据与姿态变化、H03 和 H04（或明确经审批的等效不带载安全证据）经人工评审；不得凭本次周期截图替代所有测试。
- 用户明确确认 Pan/Tilt 轴向正负、机械安装范围、安全供电/共地、动作范围与现场急停办法，且编译镜像具有带载阶段明确授权。
- 初次带载采用中位附近受限试验；全程有人监护、周围无遮挡、随时能够断舵机电源。失败则立即断电复查。

## 门禁变更

若总控批准降低历史测试要求，必须在新记录中明确替代证据/实际风险/审批人，而不是偷偷修改 `P2a_HANDOFF.md` 的原始 NOT_RUN。
