# P1a Test Plan v1.0

**原则：先无负载、后受限机械；静态/编译测试由 Codex 在具备工具时执行；任何硬件测量必须由用户取得。** 测试标准必须在采样之前批准并记录，不允许事后调整达到“通过”。

## 1. 设备与准备

- STM32F103ZET6 正点原子精英 V2；用户现有 Keil 工程与工具链；烧录/调试方式记录实际使用的方法。
- 逻辑分析仪（记录**具体型号、采样率、采样阈值、通道映射**）；建议 ≥10 MS/s，可兼顾 ±10 µs 脉宽容差的可分辨性；记录探头接线、GND、采集截图及导出原始 CSV/项目文件。
- 两路分别接 PC6（TIM3_CH1，Pan）、PC7（TIM3_CH2，Tilt），分析仪 GND 与 MCU GND 连接；**禁用时优先不接舵机信号线**。
- 舵机独立供电、MCU/云台共地已由用户确认；机械测试时现场仍核对适用电压、电流余量、逻辑电平、运动空间、机械限位。旧代码标注 S20F，实际设备与安装需要用户验证，不能仅以源码证明机械安全。
- 采样率、数字门限和线长可能影响逻辑分析仪边沿读数；不可把软件计算值当仪器测得值。分析仪读低不能区别 GPIO 主动拉低与高阻被下拉；需结合 MCU 寄存器配置/外部负载方法区分。

## 2. 参数与固定容差（预执行候选验收基线）

| 参数 | 目标 | 判据 |
|---|---:|---|
| 周期 | 20000 µs | 19900–20100 µs |
| 频率 | 50 Hz | 由实测周期推导，不单独替代周期证据 |
| 脉冲高电平 | 目标 CCR µs | ±10 µs |
| 采样数量 | 每稳定态 | ≥100 连续周期 |
| Pan | 1000/1500/2000 µs | 各点满足脉宽误差限；超限输入正确夹紧 |
| Tilt | 1200/1500/1600 µs | 同上 |
| Enable/Disable | 明确动作 | 观察完整瞬态，禁止出现非授权输出/异常宽窄脉冲 |

⚠️ 这些是工程的**事先提出的候选值**，而非 ST 芯片的产品级保证值或已实测数据。如果逻辑分析仪精度、晶振条件不能达到容差的有效判别能力，须在**采样前**审查、批准并记录新验收方案，不能根据已采集结果降低阈值。

## 3. Codex 负责的检查

| ID | 操作 | 通过条件 | 保存证据 |
|---|---|---|---|
| S01 | 记录 git HEAD/status，检查源文件所有权与旧来源 | 没有重写历史/修改旧仓库 | `git status`、diff、旧参考 SHA |

| S05 | 检查默认禁用、故障锁存、初始化失败 | 任一失败不会隐式 Enable，故障后普通 Enable 失败 | 源码审查、可执行的 host test（如适用） |

## 4. 用户实机测试顺序（不可颠倒）

| ID | 测试及步骤 | 判据 | 留存证据 |
|---|---|---|---|
| H01 | 下载最小固件，舵机**不连接**，确认 main 到初始化/禁止状态 | 固件能运行，不自动使能 | 下载与调试记录、固件 SHA |
| H02 | 不使能时测 PC6/PC7；对比复位/运行时状态 | 初始化完成后无 PWM；读取或静态审查 GPIO 模式为推挽低 | 带时基的逻辑分析仪波形、GPIO 配置记录 |
| H03 | 明确授权使能 1500/1500 µs | 双路周期和脉宽在容差内 | ≥100 周期 CH1/CH2 CSV 与截屏 |
| H04 | 仅 Pan 依次测试 1000/1500/2000，Tilt 1500 固定 | Pan 波形正确，Tilt 不随之变化 | 原始波形与测试指令/序号 |
| H05 | 仅 Tilt 依次测试 1200/1500/1600，Pan 1500 固定 | Tilt 波形正确，Pan 不随之变化 | 原始波形 |
| H06 | 测试超界（例如 Pan 0/3000、Tilt 0/3000 µs） | clamp 到各轴安全边界，无透传超范围 | 指令、结果快照、波形 |
| H07 | 在周期边界附近发双通道不同目标更新 | 两轴同步进入新周期、不出现不可解释的半帧或异常脉宽 | 同屏双通道边沿记录 |
| H08 | 手动正常 `Disable()`；再显式授权 Enable | 立即禁止持续 PWM、软件低；重新使能先双路 1500，无旧命令重放 | 断开/恢复瞬态捕获 |
| H09 | 触发经审核的**软件模拟故障路径**（不要通过损坏供电等危险方法） | 硬件输出禁止；`Enable/Apply` 拒绝；只能按批准策略复位恢复 | 故障前后两路波形、快照、复位日志 |
| H10 | 核对独立供电、共地、电平、机械间隙后连接舵机；先双轴中位再逐轴小幅移动，逐步扩大至受限范围 | 无碰撞、失控、异常重启、明显电源故障 | 供电/安装记录、动作日志或视频 |

**停止条件**：意外 PWM、通道映射错误、AFIO 导致调试不可用、初始化前异动、舵机碰撞/供电异常、波形超出边界、故障后仍能重放旧命令。立即停止机械测试，撤去舵机动力，定位原因后重测相关用例。

## 6. 总体验收与不能推断的结论

- **只编译成功**：不能证明真实 TIM3 映射、周期、GPIO 安全行为和机械安全。
- **逻辑分析仪显示停脉冲**：只能证明数字控制信号停止，不能证明舵机机械抱闸或有功能安全认证。
- **旧项目的曾经成功运行**：不能替代新 PC6/PC7 线路上的直接波形与机械证据。
- **P1a ACCEPTED**：S 类必要项 + H01–H10 适用必要项通过，保存对应 SHA 和波形；关键安全项未测不得全通过。
