## 无 SWD 调试器：CH340 烧录后 RESET 自动测试

不需要串口输入、RAM 写入或 Watch 窗口。只使用当前工程，在 Keil 的 Target 全局 C/C++ Defines 中设置下表宏；不要只给 main 或单个文件设宏。头文件默认值保持不动，不添加第二套工程。

| 固件 | 全局宏（同时保留 STM32F103xE、USE_HAL_DRIVER） |
|---|---|
| 默认禁止 | `P1A_ACTUATOR_TEST_ENABLE=0,P1A_AUTOTEST_ENABLE=0` |
| CASE 1 | `P1A_ACTUATOR_TEST_ENABLE=0,P1A_AUTOTEST_ENABLE=1,P1A_AUTOTEST_CASE=1` |
| CASE 2 | `P1A_ACTUATOR_TEST_ENABLE=0,P1A_AUTOTEST_ENABLE=1,P1A_AUTOTEST_CASE=2` |
| CASE 3 | `P1A_ACTUATOR_TEST_ENABLE=0,P1A_AUTOTEST_ENABLE=1,P1A_AUTOTEST_CASE=3` |

`P1A_AUTOTEST_CASE` 默认 1；仅接受 1/2/3，非法值编译报错。两种 ENABLE 仅接受 0/1。

1. **断开两个舵机信号和动力**，仅接 PC6、PC7 和分析仪 GND。自动脚本不得用于机械带载测试或正式控制。
2. 在同一 Keil 工程选定一个 CASE，Rebuild，确认没有错误，保存 Build Log、MAP、HEX 与 SHA256；不能烧录上次 CASE 的旧 HEX。
3. 按板卡既有串口 ISP 方法进入系统 Bootloader，用 CH340 烧录新 HEX。CH340 只是烧录通道；本固件没有 UART 命令入口。烧录后恢复用户 Flash 启动方式（BOOT0=0，其他启动跳线按板卡手册），避免 RESET 后仍进 Bootloader。
4. 逻辑分析仪先开始采集，再按 RESET。首个 C main 动作为原有关断，随后 HAL/72 MHz/InitSafe 成功后低电平等待约 2 s。复位早期仍存在芯片固有高阻阶段，不能把该阶段分析仪读低当作软件主动拉低。
5. 程序明确 Enable：先约 20 ms 全低起始帧，再双路 1500 µs。Enable 后至少等 40 ms，完成一个完整中位周期后才可能 Apply。每个 CASE 完成后 Disable，永久停留低电平；不会再次使能或循环扫动。再次按 RESET 会从头执行一次，CASE 3 的故障锁存也只有真正 MCU reset 才清除。
6. 每个状态截取 ≥100 连续周期，并保存变更前后两路瞬态；若采集内存不足，可重复 RESET，按下表时间偏移分段采集。测试结束把两个 ENABLE 恢复 0，在同一工程重建并经 CH340 刷回默认禁止固件，复核上电没有 PWM。

以下所有 `(Pan,Tilt)` 单位均为 µs；有输出时固定为 50 Hz、周期 20000 µs、计数分辨率 1 µs。表中保持 3.040 s 指 API 调用后的等待预算；预装载最多预留两个 20 ms 帧，实际新目标稳定时间至少 3.000 s。Enable 后的中位段额外包含 40 ms 保护等待。表内时间为设计标称值，尚非测量结果。

| 1 | Enable | 起始低帧 → `(1500,1500)` | 40 ms + 3.040 s |

| 3 | Apply `(3000,3000)` | 限幅 `(2000,1600)`，两轴 saturated=true | 3.040 s |
| 4 | 普通相位 Apply `(1000,1600)` | `(1000,1600)`，两轴 saturated=false | 3.040 s |

### 有界等待与判读限制

自动测试启用 Cortex-M3 DWT CYCCNT，无需调试器；不清零 CYCCNT，也不修改复位/故障标志。每个 1 ms 等待里程碑最多轮询 65536 次，外层最多 `等待毫秒数+2` 步；即使 DWT 与 Tick 同停，也不会卡在无限等待。DWT 按 72000 cycles/ms 计时，同时核对 HAL Tick，两者偏差超过 10 ms、等待超过目标+20 ms、TIM3 相位偏差超过 100 µs或运行条件检查失败均进入 `P1a_FatalError()`，先关断并锁存，再永久安全停留。Enable 后的等待不用 HAL_Delay/WFI。DWT 不可用也拒绝自动测试，不能降低检查来凑成功。

检测依赖 CPU 继续执行；轮询次数是有限工作量上限，不是独立硬件看门狗。初始化之前沿用原 HAL 时钟初始化路径（输出已关断）。该入口不是功能安全认证机制。

正常 API 失败立即进入原有 fatal 关断。CASE 3 故障后的三次预期拒绝是内部断言的一部分；若意外返回成功，仍立即强制关断并安全停留，不清除锁存来重试。运行中检查时钟、上下文、Tick/DWT、禁止/使能状态、引脚、TIM3 配置、目标和计数进度；检查与实际波形均不能互相替代。

仅 CH340 + 分析仪无法读取内部软件断言结果；提前停波或没有预定序列均应记 FAIL/待排查，完整序列后低电平也不能单独证明三个拒绝断言全部通过。相关 H 项可标注“波形部分完成，内部证据 NOT_RUN”，不可把自动脚本视为 H01–H10 全部验收，H10 更不得复用自动固件。

## 邮箱操作：一次一个命令，每次主动提交

在 Watch/Memory 中观察 `g_p1a_test`。首次 `request_seq=ack_seq=0`。每次先确认前一条已 ack，然后写参数/动作/key，**最后**把 `request_seq` 改为新的数值（例如依次 1、2、3）。保持运行，等待 `ack_seq==request_seq` 后读取 `status/result/snapshot`。结构体顺序见 `App/p1a_test/p1a_test.h`，使用字段名而非手算地址。

| 动作 | action | 提交前设置 | 预期返回（不是实测） |
|---|---:|---|---|
| 普通禁止 | 1 | 无 | status=1；enabled=false；引脚低；不清故障 |
| 新授权使能 | 2 | **每次重写** enable_key=`0xC2061500` | 正常 status=1；双路中位；key 被消耗为 0 |
| 双轴目标 | 3 | pan_us / tilt_us，单位 µs | 正常 status=1；result 为请求/限幅值 |
| 周期边界附近请求双轴目标 | 6 | pan_us / tilt_us；先稳定运行 | status=4 时正在等 CNT≥19980，未 ack；随后如 action=3；dispatch_counter 为调用前采样 |
| 软件模拟紧急故障 | 4 | 无；仅无舵机时做 H09 | status=1 表示故障调用已执行；snapshot.fault_latched=true |
| 重复初始化/刷新诊断 | 5 | 无；仅禁止状态正常使用 | 禁止且无故障时 status=1；运行或故障时拒绝并锁存 |

`status=2` 是驱动拒绝（输出关断并故障锁存）；`status=3` 是缺少使能 key 或未知动作（普通 Disable，不清已有故障）。action=6 每次 Poll 最多检查一次，不忙等；65536 次未遇窗口就锁存关闭，不依赖 HAL Tick。此轮询预算不是毫秒时限；若未命中窗口应记录失败原因后重新评估，不调大到无界等待。不要通过手改内部状态、TIM3/GPIO 或故障标志绕过 API。邮箱仅是监督测试入口，无远程权限/安全认证含义。故障后必须执行真正的 MCU reset 并重新走 main；单独设置 PC 到 main 或调试器“重跑”函数不能算复位。

Enable 后设计上有一个约 20 ms 的全低起始帧，随后自然更新同时装载双路 1500 µs。**至少等待 40 ms，且最好完成 ≥100 周期采集后再 Apply**。首次自然更新之前的 Apply 会主动关断并锁存，防止覆盖首次中位。这个延时、首脉冲和同步性都必须由实际波形确认。

## 失败、错刷与结束

出现意外 PWM、错误映射、失去调试连接、超限波形、旧目标重放、碰撞或供电异常，立即停止并撤去舵机动力。调试链路/邮箱正常时可先 action=1；若已失联，不依赖软件停止。保存失败证据并报告，不继续扩大机械范围或调整容差凑通过。

结束时 Disable、断开舵机动力，把同一工程 `P1A_ACTUATOR_TEST_ENABLE` 与 `P1A_AUTOTEST_ENABLE` 均恢复为 `0`（或删除覆盖），重新构建并刷入默认禁止固件，复核 H01/H02；保存其真实哈希。不能只改源码就宣称设备已经恢复。

记录使用 [test_plan.md](test_plan.md) 的完整模板；每项填 PASS / FAIL / NOT_RUN，并关联具体源码哈希、固件哈希、seq、CSV 与截图。P1a 未验收前不进入 P1b。
