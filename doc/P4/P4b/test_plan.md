# P4b — T2/T3 两组实机测试

与P4a T1加总只有三组。用户可使用的工具只有CH340串口、逻辑分析仪；**没有万用表/示波器/在线调试器**。

## T2：ADC1 TIM2_CC2 DMA采样

**前置接线检查（必须在上电改变接线前完成）**：确认开发板 P7 多功能接口中 `STM_ADC` 实际通到 PA1，检查 TPAD 与 STM_ADC 是否存在短路帽并在需要时移除；PA7 是SPI1 MOSI不可碰；确定 RV1 的电压范围属于 ADC 输入安全范围，`VDDA/VSSA` 正常供电、外部信号与MCU共地。不要将5V直接施加PA1。**未确认的RV1-P7走线不得直接短接**；只有经板级手册/实际丝印确认后使用 RV1 → STM_ADC 作为可调输入。没有安全中间电平条件时仅做安全的GND/3.3V端点，并如实记录覆盖不足。

操作（仍是一组测试）：

1. 下载P4b固件，BOOT0=0 + RESET，打开115200串口助手。运行 `ADC?`，确认有效样本 `n` 增长；连续看多条每200ms ADC 报告；不得是固定假数值。
2. 将 **PA1安全接到板级GND**，记录raw/avg接近低端（受地噪声影响不要求严格0）。
3. 若已确认RV1可提供0到VDDA内安全中间电平，连接RV1到 `STM_ADC`，调节RV1观察raw/avg连续变化；未确认则跳过并记PENDING事项。
4. 将PA1**安全接到经确认的板上3.3V参考**，观察raw/avg趋于高端。不同输入状态之间样本和报告应持续更新。

**PASS判断**：有效raw/avg范围0..4095，GND/中间/高参考数值排序合理，n持续增长且频率与1kHz设计大致一致（32样本半窗统计导致约32样本粒度），DMA不停止。**不要把近似 `mv` 当实测绝对电压**；未做中间电平时在记录说明测试覆盖限制，由用户/总控决定是否足以验收。

## T3：CAN + IMU + UART + ADC 简短并发

保持现有CAN通信与STATUS读取；IMU按现有10ms任务采样；USART1可以 `PING`/`COUNT?`/`ADC?`；ADC自动输出约每200ms一行。观察CAN STATUS持续，UART可回应，ADC n持续累积，既有控制安全默认行为不异常。舵机优先无负载且不扩大现有安全授权，不重新跑P3长测试。

**PASS判断**：四功能短时并发无明显停止/异常，无ControlTask调度失常，CAN STATUS正常。无全面WCET/长压测要求。
