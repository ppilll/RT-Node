# P4a — T1 唯一实机测试

**前提**：PC 能使用板载 CH340 打开串口。用户手动 BOOT0=1+RESET 进入 STM32 系统 Bootloader 下载；完成后 BOOT0=0+RESET 运行用户程序，关闭下载软件占用的 COM，115200/8N1、无流控。Bootloader 不与用户程序并行使用 USART1。

**一组测试含四个操作**（可手动操作，或使用串口助手/Python，不要求增加自动化脚本文件）：

1. 发 `PING\n`，预期 `PONG`；发 `COUNT?\n`，应得到合理 `RX`/`OVF` 计数。
2. 分两次发 `PI`、`NG\r\n`（间隔明显超过 IDLE 帧时间），预期仅完整换行后 `PONG`。
3. 连续发多条 `PING\n`，检查每条有一次回复；连续流不依赖 IDLE。选择串口收发吞吐可维持的命令数/节奏，避免故意制造不可服务的无限突发。若已检测溢出，应在输出和统计中明确反映。
4. 让累计输入字节总数超过多个 256B 环形周期，确认跨缓冲区尾部/头部的命令仍正确；可以配合 COUNT? 累计字节数与接收日志判断，不要求精确控制 DMA 起始位置。只需同一组 T1 记录。

**PASS**：每个可接受的完整行得到对应回复、分段/回绕无错误解析、持续输入可被有界消费、未干扰现有任务，COUNT 合理；如果触发 DMA 覆盖，必须报告 OVF 且安全丢弃损坏行。只要普通测试负载未导致覆盖，不需要专门故障注入来证明覆盖计数。

记录最少五项：`操作`、`预期`、`实际`、`PASS/FAIL`、若必要附几行串口回显或 PA9/PA10 逻辑分析仪截图。硬件测试只能由用户填写，Codex 不得编造。
