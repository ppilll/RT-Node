# T1 — BME280 I²C2 核心实机测试

前提：用户接好 PB10/PB11、CSB=高、SDO=GND、3.3V/GND；不要把 I²C2 当成 I²C1。设备真实 ACK 与硬件安全已由用户确认接线，但数据测试仍待执行。

| 步骤 | 工具/动作 | 预期 |
|---|---|---|
| T1-1 | 上电后逻辑分析仪观察 I²C2 SCL/SDA；必要时以短受控查询读 ID `0xD0` | 7 位 `0x76` ACK（如实际接线地址为 0x77 则记录并按用户许可改地址），ID=`0x60` |
| T1-2 | PC CH340 115200 8N1 发送 `ENV?` | 单行有效补偿温度/湿度/气压，单位明确，不输出裸寄存器值 |
| T1-3 | 轻微改变温湿环境；重复数次 `ENV?` | 温湿数值随条件变化；气压在合理范围，读数和 tick 更新 |
| T1-4 | 复查 `PING`、`COUNT?`、`ADC?`（仅简单冒烟，不复测 P4 全量） | 仍保持既有响应；IMU/CAN/Control 不因 ENV 普通错误停机 |

一组测试即可。**记录模板**：日期/固件提交、模块地址、ID、实际 ENV 输出、是否 PASS/FAIL、问题/截图(可选)。未测 = NOT RUN，不能推断 PASS。不要求精度标定或哈希核验。
