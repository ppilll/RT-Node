# P2a 接线、供电与逻辑分析仪指南

## 实物依据

- 用户在 2026-10-17 提供模块正反面照片。正面文字从上至下：`VCC/GND/SCL-SPC/SDA-SDI/SA0-SDO/CS/INT/FSY`；照片上最后一脚为 **FSY**，并非 FST。
- 用户明确模块 VCC 由开发板 **3.3 V** 供电；不使用 5 V。芯片 VDD/VDDIO 官方工作范围 1.71..3.45 V。
- 对照片背面元器件的可见性不足以逆推出完整电路原理图、供电稳压拓扑或 ESD 保护；本任务不需要为已确认的 3.3 V 供电继续展开复杂审查。
- FSY 根据丝印与 ICM20602 引脚定义推定为 FSYNC；官方建议未用时接 GND。首次接线之前检查卖家文字或通断关系若有信息相矛盾，则悬置该脚并报告，不推测电压输出。

## 冻结的引脚连接

| 模块正面丝印 | MCU 端 | 备注 |
|---|---|---|
| VCC | 3.3V | **仅 3.3 V** |
| GND | GND | MCU/逻辑分析仪共地 |
| SCL/SPC | PA5 | SPI1_SCK |
| SDA/SDI | PA7 | SPI1_MOSI，主机→IMU |
| SA0/SDO | PA6 | SPI1_MISO，IMU→主机 |
| CS | PC4 | 软件 GPIO 片选，空闲高、事务低 |
| INT | 不连接 | P2a 轮询 |
| FSY | GND（按 FSYNC） | 不用外部同步；若商家资料有异议先暂停此接线 |

SPI1 使用默认 AF 映射，不允许启用 SPI1 重映射而改动 AFIO->MAPR 的 P1 保留位。PA4 不使用；使用 PC4 GPIO 片选是为了与现有 P1 引脚保持分离。PC4 与板上某些可选外设功能可能复用，P2 不启动它们。

## 接线顺序

1. MCU 断电、舵机信号/独立舵机电源断开；确认这八脚的物理顺序与照片中的模块正面一致。
2. 先接 GND、3.3V，再接 PA5/PA7/PA6/PC4；如 FSY=FSYNC 得到模块层面确认，接 GND；INT 悬空不接。
3. 线尽量短、固定线束并避免手持时牵拉接插件；不要热插拔作为首轮故障测试。
4. 烧录仅 P2a 的安全镜像，默认执行器不使能；第一次只通电观察 SPI，禁止连接舵机动作负载。

## 逻辑分析仪

| 通道 | 信号 | 首轮目的 |
|---|---|---|
| CH0 | PC4 CS | 每事务选中/释放 |
| CH1 | PA5 SCK | Mode3、时钟频率 |
| CH2 | PA7 MOSI | `WHO_AM_I` 读指令首字节 0xF5、Burst 0xBB |
| CH3 | PA6 MISO | ID 应在随后数据字节收到 0x12，Burst 返回 14 字节 |
| 另一次测量 | PC6 / PC7 | 没有 50 Hz PWM 输出，静态低电平（需在适当逻辑阈值下确认） |

SPI 解码器：CPOL=1、CPHA=1（即 Mode 3）、8 位 MSB first。初始建议采样率不低于 5 MS/s；具体按逻辑分析仪硬件能力调整并记录。STM32 SPI 线上主机读寄存器流程：`CS低 → MOSI发送 (reg|0x80) → 继续时钟读取 N 字节 → CS高`；发送填充值不代表真实传感器数据。

身份验证：`reg=0x75`，首字节 `0xF5`，第二数据字节为 `0x12`。原始采样 `reg=0x3B`，首字节 `0xBB`，随后 14 字节为 AxH,AxL,AyH,AyL,AzH,AzL,TempH,TempL,GxH,GxL,GyH,GyL,GzH,GzL。

禁止直接短接供电与信号线做故障注入。**逻辑分析仪不能证明 3.3V 实际幅度、上升沿模拟质量或软件执行时间。** 如需这些量测且没有适当仪器，标 NOT_RUN。

## 首次无调试器测试排障

- CS 无动作：核实程序烧录、PC4 初始化、任务创建和固件编译宏；不能假定 CH340 下载成功意味着应用正在运行。
- 有 SCK 但 ID 非 0x12：核实 PA6/PA7 有没有反接、Mode3、引脚映射、CS 空闲状态，检查供电和地。
- ID 正确而 Burst 不动：检查复位/寄存器配置和采集循环，优先保存完整 LA 原始文件。
- 数据随姿态改变但输出角度不正确：先运行主机解码/姿态算法单测，不依赖 SWD Watch。
