# P2a 操作者最小实机步骤

本会话没有连接/烧录/操作开发板。以下 H01–H04、机械/LA 测试均为 **NOT_RUN**；主机测试不能代替它们。P2b 未批准。

## 1. 固件身份与接线

使用本次已构建镜像 **`doc/P2a/evidence/armcc/RTnode.hex`**。
SHA-256：`F37665E188B8F731138FE37DA11BA8E2ACF2E41CE7C91F40A8E70733EFD740D5`。

构建脚本在保存证据后恢复了原有 Projects 目录的输出；因此此时 `Projects/RTnode.hex` 是先前文件，**不能用它冒充本次 P2a 镜像**。用户在 Keil 对更新后的原工程自行 Rebuild 也可以生成新的镜像，需重新记录其 hash。

1. 断 MCU 电源，断开舵机信号线和独立供电。
2. 模块 VCC→3.3V，GND→GND，SCL/SPC→PA5，SDA/SDI→PA7，SA0/SDO→PA6，CS→PC4；INT 不接。短线固定，确认 PC4/PA5–7 无其它外设驱动。
3. **FSY 最终接线待用户核实模块端确为 FSYNC**；确认后未使用的 FSYNC 接 GND。存在相矛盾板级资料时暂停该脚接线并报告。软件不配置 FSYNC。
4. 按既有 CH340 Bootloader 流程烧录上述 HEX，恢复正常 BOOT 启动设置。应用不提供 UART 日志；下载成功本身不能证明任务正常运行。

## 2. H01：上电配置、ID、SPI 电气活动

- LA 共地；CH0=PC4，CH1=PA5，CH2=PA7，CH3=PA6。
- SPI Mode3（CPOL=1、CPHA=1），8bit、MSB-first，采样率建议≥5MS/s；记录型号、实际采样率及阈值。
- 从复位/上电前开始捕获约 5 秒。CS 空闲高；SCK 空闲高，候选线速 562.5kHz。
- 查 `F5 00`，第二字节 MISO=12。其后应见 `6B 80` 软件复位；复位等待和有界检查后有 `70 40`、`6B 01`、`6C 00`、`1A 03`、`19 09`、`1B 00`、`1C 00`、`1D 03`，以及关闭 FIFO/INT/USER_CTRL 的写入；所有关键配置都有读回。
- 初始静止约 1 秒校准（须100连续静止样本，最长3秒）。若校准失败，本版停止正常 SPI 采集，需检查原因后复位；没有自动重连。
- 保存原始 capture、全部通道带时间戳 CSV、ID 与配置写入/读回截图。

## 3. H02：14 字节、采集节拍与人工姿态

- 解码 `BB` 后14字节：AxH/L、AyH/L、AzH/L、TempH/L、GxH/L、GyH/L、GzH/L。每次CS窗口总15字节，单个连续burst。
- 保留至少10个连续burst，记录起始时刻和间隔，目标约10ms；这是采集活动代理，不能当作精确任务唤醒/WCET测量。
- 静止完成校准后，轻缓正负倾斜、回正，再捕获原始字节。大端有符号16位；加速度÷16384=g，陀螺÷131=deg/s。水平时合重力约1g，芯片实际安装方向决定重力落在哪一轴。
- 本版只有 RAM 中姿态快照，没有已批准的外部角度读出通道。LA 可核对原始输入，**不能声称已测到滤波输出或实机角度精度**。无读出证据的运行栈水位/算法执行时间保留 NOT_MEASURED。

## 4. H03：PC6/PC7 无 PWM

- 舵机仍断开。另一次捕获 PC6/PC7，从上电覆盖初始化和持续采集数秒。
- 预期两线保持静态低，无50Hz PWM。记录窗口、阈值和截图；短窗口不能证明“永远无PWM”。

## 5. H04：设备缺失有限失败

- MCU断电后移除IMU，再上电，保留CS/SCK/MOSI/MISO及必要的PC6/7记录。
- 不匹配ID最多2次；无正常burst。任何HAL SPI错误立即释放CS并停止后续传输。物理缺失常表现为读0/FF而非HAL超时，不得把SPI当有ACK的总线。
- 结合源码/主机有限失败证据和LA，记录实际观察。若外部无法直接读到 FAILED，就明确其属于内部状态；不编造失败耗时或状态读数。禁止热插拔或短路注入。
